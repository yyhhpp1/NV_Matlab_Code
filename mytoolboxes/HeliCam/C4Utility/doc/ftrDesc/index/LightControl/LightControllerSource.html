  • Off: Disable the Light Controller.

  • UserOutput0: Light Controller is controlled by UserOutpu0.

  • UserOutput1: Light Controller is controlled by UserOutpu1.

  • SFIO5: Select the external analog input SFIO5 on the LIA Module as signal source of the Light Controller.

  • SignalGenerator: Select the internal SignalGenerator (part of the LIA module) as source of the Light Controller. The Signal Generator is configured by the features where the name starts with SignalGenerator.
