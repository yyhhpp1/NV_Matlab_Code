Enumeration gives the channel type to which the part selected by ChunkPartSelector belongs.

  • Unknown: Unknown part type or type not available now.

  • Surface: (enabled by component Range or Intensity) This part contains range information. The numeric value represents range in units specified as the product of ChunkPartFixpointScaling times ChunkScan3dDistanceUnit.

  • Amplitude: (enabled by component Reflectance) This part contains amplitude information. The numeric value represents estimated ADC signal amplitude at the peak of the signal, expressed in units of ChunkPartFixpointScaling ADC counts.

  • Phase: (enabled by component Phase) This part contains phase information. It represents the demodulation phase at the peak of the signal, expressed in units of ChunkPartFixpointScaling radians.

  • Confidence: (enabled by component Confidence) This part contains confidence information. The numeric value represents the Bayesian posterior probability that the extracted surface information does represent a real surface (as opposed to random noise), as a fraction in the range 0 to 1.

  • pZglobal: (enabled by component RangePrecision and configured by PrecisionScale) This part contains global range precision or uncertainty information. If PrecisionScale is set to InverseStandardDeviation, the output is precision (which is the inverse of uncertainty). The numeric values represents either one sigma of uncertainty in units specified as the product of ChunkPartFixpointScaling times ChunkScan3dDistanceUnit, or the inverse of that.

  • pZlocal: (enabled by component RangePrecision and configured by PrecisionScale) This part contains local range precision or uncertainty information, valid for the comparison between pixels that are within the same phase-unwrapping region/group (see also channel unwrap-group). If PrecisionScale is set to InverseStandardDeviation, the output is precision (which is the inverse of uncertainty). The numeric values represents either one sigma of uncertainty in units specified as the product of ChunkPartFixpointScaling times ChunkScan3dDistanceUnit, or the inverse of that.

  • pZenvelope: (enabled by component AdditionalProcessingChannels) This part contains the equivalent of pZ of the intermediate (envelope-based) centre of mass algorithm, when followed by phase-unwrapping.

  • pP: (enabled by component AdditionalProcessingChannels and configured by PrecisionScale) This part contains the precision or uncertainty information of the phase component. If PrecisionScale is set to InverseStandardDeviation, the output is precision (which is the inverse of uncertainty). The numeric values represents either one sigma of uncertainty in units of radians, or the inverse of that.

  • unwrap_group: (enabled by component RangePrecision) This part associates each pixel with a phase-unwrapping group, identified by the numerical index value. The special value 0 is assigned to pixels belonging to very small phase-unwrapping group, typically low confidence pixels. Pixels within the same group are connected through successful phase-unwrapping, and therefore the relative accuracy is better than between independent groups. Then, the relative accuracy should be determined from sZ-local/pZ-local rather than sZ/pZ.

  • Zenvelope: (enabled by component AdditionalProcessingChannels) This part contains the equivalent of Z of the intermediate (envelope-based) centre of mass algorithm, when followed by phase-unwrapping.

  • I: (enabled by component Intensity) in-phase information of raw data. Only available in ‘Scan3dExtractionMethod’ = rawIQ

  • Q: (enabled by component Intensity) Quadrature information of raw data. Only available in ‘Scan3dExtractionMethod’ = rawIQ
