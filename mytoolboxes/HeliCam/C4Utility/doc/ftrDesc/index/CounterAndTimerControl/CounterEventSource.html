Select the events that will be the source to increment the counter.

  • Off: Counter is stopped

  • AcquisitionTrigger: Counts the number of AcquisitionStart Triggers.

  • AcquisitionTriggerMissed: Counts the number of missed AcquisitionStart Triggers.

  • FrameTrigger: Counts the number of FrameStart Triggers.

  • FrameTriggerMissed: Counts the number of missed FrameStart Triggers.

  • RTIO4: Counts the number of transitions on I/O Line RTIO4.
