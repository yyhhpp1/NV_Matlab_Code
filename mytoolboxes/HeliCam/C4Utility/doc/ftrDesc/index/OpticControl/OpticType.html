Select the optic type to load predefined configurations. This writes implicit the features Magnification, NumericalAperture, WavelengthCorrection and TargetVerticalSpacing. If a user application changes one of this optics relevant features, the OpticType changes to Custom. This feature is only available for OpticControlSelector=Fixed.

  • Custom: The optic relevant parameters are configured by the user.

  • WLI8_X2: Select the heliInspect H8 WLI8-X2 optic.

  • WLI8_X4: Select the heliInspect H8 WLI8-X4 optic.

  • WLI8_X8: Select the heliInspect H8 WLI8-X8 optic.

  • MIRAU_X10: (Deprecated!) Select the heliInspect H8 MIRAU-X10 optic.

  • MIRAU_X20: (Deprecated!) Select the heliInspect H8 MIRAU-X20 optic.

  • MIRAU_X50: (Deprecated!) Select the heliInspect H8 MIRAU-X50 optic.

  • MIRAU_X100: (Deprecated!) Select the heliInspect H8 MIRAU-X100 optic.

  • LM_MIRAU_X10: Select the heliInspect H8 WLI8-Mirau + Leitz 10x optic.

  • LM_MIRAU_X20: Select the heliInspect H8 WLI8-Mirau + Leitz 20x optic.

  • LM_MIRAU_X50: Select the heliInspect H8 WLI8-Mirau + Leitz 50x optic.

  • MT_MIRAU_X20: Select the heliInspect H8 WLI8-Mirau + Mitutoyo WLI Plan Apo 10x optic.

  • MT_MIRAU_X50: Select the heliInspect H8 WLI8-Mirau + Mitutoyo WLI Plan Apo 25x optic.

  • H9L_X0_5: Select the heliInspect H9 H9L-X0.5 optic type.

  • H9L_X0_8: Select the heliInspect H9 H9L-X0.8 optic type.

  • H9L_X1_0: Select the heliInspect H9 H9L-X1.0 optic type.

  • H9L_X2_0: Select the heliInspect H9 H9L-X2.0 optic type.

  • H9S_X0_5: Select the heliInspect H9 H9S-X0.5 optic type.

  • H9S_X0_8: Select the heliInspect H9 H9S-X0.8 optic type.

  • H9S_X1_0: Select the heliInspect H9 H9S-X1.0 optic type.

  • H9S_X1_5: Select the heliInspect H9 H9S-X1.5 optic type.

  • H9S_X2_0: Select the heliInspect H9 H9S-X2.0 optic type.

  • H9S_X3_0: Select the heliInspect H9 H9S-X3.0 optic type.
