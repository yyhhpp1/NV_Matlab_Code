ScanMode

Select scanning mode used for data acquisition. In a measurement/acquisition sequence the selected mode is used for controlling the motion.

  • None: Motion is disabled.

  • DownAndWait: Measure the surface when move downward. Wait at the end position after the measurement.

  • UpAndWait: Measure the surface when move upward. Wait at the end position after the measurement.

  • Smart: Select the closest position as start position and measure up or downward. Wait at the end position after the measurement. This Mode is not supported when multiple segments are active (VerticalSegmentEnable).

  • Down: Measure the surface when move downward. Move back to the start position after the measurement.

  • Up: Measure the surface when move upward. Move back to the start position after the measurement.
