GenDCStreamingMode

Name

GenDCStreamingMode

Type

Enumeration

Visibility

Guru

AccessMode

RW

EnumEntry

Off

On

Controls the device’s streaming format. Note: This feature is meant to globally control the data streaming format of the device. As such, it has priority over other features (except TestPayloadFormatMode) that might influence the output payload format or content

  • Off: The device will only stream data in its native format.

  • On: The device will stream all its data in the generic GenDC format.
