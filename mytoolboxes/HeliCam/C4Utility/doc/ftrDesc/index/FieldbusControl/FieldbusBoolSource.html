If the selected FieldbusBool Slot is a camera output signal, this feature is writable and configures which internal state or acquisition signal is mapped to the FieldbusBool slot. The FieldbusState is true if the internal state or signal is active. Otherwise it is false.

  • Off: The selected bool slot is disabled. The state is set to false.

  • UserOutput0: Map Selected FieldbusBool to UserOutput0.

  • UserOutput1: Map Selected FieldbusBool to UserOutput1.

  • UserOutput2: Map Selected FieldbusBool to UserOutput2.

  • UserOutput3: Map Selected FieldbusBool to UserOutput3.

  • UserOutput4: Map Selected FieldbusBool to UserOutput4.

  • UserOutput5: Map Selected FieldbusBool to UserOutput5.

  • UserOutput6: Map Selected FieldbusBool to UserOutput6.

  • UserOutput7: Map Selected FieldbusBool to UserOutput7.

  • FrameTriggerWait: Device is currently waiting for a frame start trigger to start a measurement.

  • FrameTriggerMissed: Device has missed a FrameStart trigger. Is reset when switching between acquisition and configuration mode.

  • FrameActive: Device is currently doing a measurement.

  • RecordingTriggerWait: Device is currently waiting for a recording start trigger.

  • RecordingTriggerMissed: Device has missed a Recording trigger. Is reset when switching between acquisition and configuration mode.

  • RecordingActive: Device is currently doing a recording.

  • StreamTransferActive: Transfer on the stream is active. e.g. Frame transfer from the device to the host computer is active.

  • StageInMotion: Device is currently moving the stage.
