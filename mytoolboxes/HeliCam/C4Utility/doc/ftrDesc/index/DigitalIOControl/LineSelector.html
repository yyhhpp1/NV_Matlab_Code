Select the physical line (or pin) of the external device connector or the virtual line of the Transport Layer to configure. When a Line is selected, all the other Line features will be applied to its associated I/O control block and will condition the resulting input or output signal.

  • Line0: Digital IO 0: HPS Input 0, HpsHhprt1v8io0

  • Line1: Digital IO 1: HPS Input 1, HpsHhprt1v8io1

  • Line2: Digital IO 2: HPS Output 0, HpsHhprt1v8io2

  • Line3: Digital IO 3: HPS Output 1, HpsHhprt1v8io3

  • RTIO2: heliDriver D3 realtime output RTIO2 on RTIO or LIA Module

  • RTIO3: heliDriver D3 realtime output RTIO3 on RTIO or LIA Module

  • RTIO4: heliDriver D3 digital input RTIO4 on RTIO Module

  • DIO1: heliDriver D3 digital input/output DIO1 on DIO or LIA Module

  • DIO2: heliDriver D3 digital input/output DIO2 on DIO or LIA Module
