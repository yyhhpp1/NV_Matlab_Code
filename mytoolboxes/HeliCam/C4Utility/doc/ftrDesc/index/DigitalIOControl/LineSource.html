Selects which internal acquisition or I/O source signal to output on the selected Line. LineMode must be Output.

  • Off: Selected Line is not an output or output is off.

  • UserOutput0: Map Selected Line to UserOutput0.

  • UserOutput1: Map Selected Line to UserOutput1.

  • UserOutput2: Map Selected Line to UserOutput2.

  • UserOutput3: Map Selected Line to UserOutput3.

  • UserOutput4: Map Selected Line to UserOutput4.

  • UserOutput5: Map Selected Line to UserOutput5.

  • UserOutput6: Map Selected Line to UserOutput6.

  • UserOutput7: Map Selected Line to UserOutput7.

  • FrameTriggerWait: Device is currently waiting for a FrameStart trigger to start a measurement.

  • FrameTriggerMissed: Device has missed a FrameStart trigger. Is reset when switching between acquisition and configuration mode.

  • FrameActive: Device is currently doing a measurement.

  • RecordingTriggerWait: Device is currently waiting for a recording start trigger.

  • RecordingTriggerMissed: Device has missed a Recording trigger. Is reset when switching between acquisition and configuration mode.

  • RecordingActive: Device is currently doing a recording.

  • StreamTransferActive: Transfer on the stream is active. e.g. Frame transfer from the device to the host computer is active.

  • StageInMotion: Device is currently moving the stage.

  • LockInReference: Map selected line to the Lock-In Reference Signal. This is a real-time information coming from the image sensor.
