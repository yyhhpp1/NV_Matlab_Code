C4Hdl: Main Page

Overview

The C4Hdl library is based on the GenTL producer diaphus and the GenICam reference implementation. The library provide a proprietary interface for heliotis cameras. The interface is available in the following programming languages:

  • C
  • CLR/C#
  • Python 2.7
  • Python 3.5
  • LabVIEW

The structure in modules is according to the GenICam standard definition, whereby each module is wrapped in its own class. The documentation of the standard is available on emva.org and the heliotis Programmer Guide contains a short summery of the relevant parts.

How to Start

Application using the C4Hdl library has to start with an object of the C4Handler class. This class provide an interface to the GenICam system module and has methods to create objects from the interface module C4Interface according to the GenICam standard. Based on the C4Interface objects of the device module C4Device are created which in thurn has methods for the buffer module C4Buffer access.

Each module (except C4Handler) has methods to read and write features. Additional meta information of the feature are encapsulated in the C4FeatureInfo class.

For each supported language a simple example with the name h8SurfSimp is provided in the subdirectory _./c4hdl/win64-x64/examples_ of the installation directory. It demonstrate how to create the different objects, how the device configuration is done and data are acquired.
